# Tristate and Bidirectional Ports
Date: 2026-10-17
Status: Planning (PLANv2.md approved in interview)

Adds bidirectional `bus` ports (spelled `outgoing bus`/`incoming bus`),
`net` declarations (multiply-driven signals), absence-as-Z tristate driving
via `#=`, and `pullup`/`pulldown` weak-drive primitives to Virdant,
enabling bidirectional connectivity alongside the existing `incoming`/`outgoing` port model.

Canonical plan: `PLANv2.md` (supersedes `PLAN.md`).
